# Post Test

A small Next.js app for practicing App Router pages, client components, and data fetching.

It lists sample blog posts from [JSONPlaceholder](https://jsonplaceholder.typicode.com/), shows a per-post view counter, and opens a detail page for each post.

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use **View Posts** to browse the list, then **Read full post** for a single post.

`npm start` is the production server (`next start`). It needs `npm run build` first and will fail if port 3000 is already in use.
